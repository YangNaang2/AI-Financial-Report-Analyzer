선택 Transformer 테스트는 torch/transformers가 없으면 건너뜁니다. GitHub CI는 핵심 requirements만 설치하므로 이 테스트 1개는 제외되고 나머지 99개가 실행 대상입니다. CI 결과는 저장소 Actions 및 PR에서 확인합니다.

## 실제 입력과 외부 연동

- 저장소에 이미 있던 `한미반도체.pdf`: 6페이지, 9,206자, 11구간, 추출된 텍스트 전 범위 규칙 분석.
- 저장소에 이미 있던 `미래에셋증권.pdf`: 7페이지, 12,363자, 13구간, 추출된 텍스트 전 범위 규칙 분석.
- 위 두 문서를 실제 브라우저에서 함께 업로드 → 추출 성공 2개 → 분석 완료 → 대시보드 문서/분석 각 2개 확인.
- 네이버 현재 공개 API 실제 첫 목록 15건, 다음 페이지 15건의 중복 0건 확인. 첫 보고서만 대상으로 실제 상세 조회·PDF 다운로드 성공, 같은 작업 재실행 시 다운로드 0건/기존 파일 건너뜀 1건 확인.
- 가격 공급자 라이브 데이터의 정확도·조정 정책은 검증하지 않았습니다. 라벨 로직은 고정 가격 시계열을 주입한 테스트로 검증했습니다.

## 실제 브라우저

Codex in-app browser에서 로컬 Streamlit 서버에 접속해 다음을 확인했습니다.

- 모델 없는 첫 화면과 가상 데모 대시보드
- 텍스트 입력, 메타데이터 확인, 실제 백그라운드 분석 완료와 저장된 상세
- 기존 PDF 2개 동시 업로드·추출·규칙 분석·저장
- 페이지·문단 선택과 원문 강조, 데모 보고서 비교, 보관함
- 최종 코드에서 서버를 다시 시작해 캐시 이전 버전의 영향을 제거한 후 재검증

스크린샷은 가상 기업과 데모 데이터만 포함합니다. 개인 원문·DB·실제 분석 기록을 스크린샷이나 소스로 새로 공개하지 않았습니다.

## 모델 검증의 정확한 범위

TF-IDF/로지스틱 회귀는 합성 문서 데이터로 실제 학습·평가·저장·재로딩·추론·백업 복구를 실행했습니다. Optional Transformer는 로컬에서 만든 소형 BERT(16 hidden, 1 layer, 2 heads)와 fast tokenizer를 CPU로 합성 문서 40개에서 1 epoch 학습하고, 24/8/8 시간 분할과 긴 문서 구간 추론·safetensors 저장·SQLite 복구를 검사했습니다. 외부 모델 다운로드나 GPU 사용이 없었습니다.

로컬 선택 패키지: torch 2.14.0+cu130, transformers 4.57.6. 테스트는 CPU로 강제 실행했습니다. 소형 무작위 초기 모델은 연결 경로를 검증하는 테스트 도구이며 제품용 금융 모델로 등록하거나 제공하지 않았습니다.

**실제 금융 리포트 보류 테스트셋으로 검증한 모델은 없습니다.** KoFinBERT 전체 학습, 확률 보정, 투자 수익성, 한국어 OCR, 공개 다중 사용자 서비스 운영은 이번 검증에 포함되지 않습니다.
