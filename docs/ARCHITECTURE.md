# Report Lens 구현 노트

## 모듈과 경계

- `data_processor.py`: PDF/텍스트 추출, 페이지·문단·페이지 내 문자 위치, 보수적인 메타데이터 및 수치 추출, 공통 구간 생성.
- `inference.py`: 점수가 없는 규칙 탐지, 안전한 JSON 기준선, 선택 Transformer 추론, 완료 manifest/체크섬/라벨 매핑 검증, 버전 캐시.
- `storage.py`: SQLite WAL, 명시적 owner, 트랜잭션, 실행별 원문·메타데이터 스냅샷, 백업 검증.
- `exports.py`: UTF-8 BOM CSV, 전체 실행 JSON, 외부 스크립트가 없는 HTML 보고서. CSV 수식 입력과 HTML 삽입 방어.
- `crawler.py`, `labeler.py`, `train.py`, `main.py`: 단계별 수집, 관측 라벨, 날짜 분할·평가. import 또는 앱 재실행이 학습을 시작하지 않음.
- `jobs.py`: 최대 2개 백그라운드 스레드, 공간별 활성 작업 1개, 실제 단계 진행, 오류/중지/완료, 제한된 작업 이력.
- `app.py`, `demo.py`: 6개 Streamlit 화면과 가상 체험 데이터. 사용자 원문을 외부 AI 서비스로 보내지 않음.

## 분석의 의미

클래스 1(negative)은 정의된 관측 기간에 설정한 가격 하락이 발생했다는 **대리 라벨**이다. 추천의 진실성이나 애널리스트의 의도를 뜻하지 않는다. 점수는 모델의 해당 클래스 출력이며 보정된 미래 하락 확률이 아니다. 규칙 탐지는 단어의 출현을 표시할 뿐 점수로 변환하지 않는다. 원문 발췌는 생성 요약이 아니며 인과적 설명이 아니다.

문서 점수는 선택한 구간의 음성 클래스 점수를 **동일 가중 산술 평균**한다. 학습 평가도 동일하게 문서별 구간 점수를 평균한다. 길이가 다른 구간의 가중치는 같고, 겹친 텍스트는 두 구간 점수에 영향을 줄 수 있다. 의미 중요도나 매매 신호로 해석하지 않는다. 문서 길이/구간 설정이 다른 결과를 무조건 비교하지 않는다.

기본 구간은 최대 256토큰, 겹침 32토큰이다. Transformer는 해당 로컬 토크나이저의 실제 토큰 위치와 특수 토큰 수를 사용하며 경계에서 다시 토큰화해 한도를 검증한다. 기준선/규칙은 공백 및 32자 단위를 사용한다. 원문 위치는 **정규화된 페이지 텍스트의 문자 오프셋**이다. 원본 PDF의 픽셀 좌표/표 구조와 다를 수 있다.

분석 범위는 구간이 덮는 문자 구간의 합집합 / 추출된 페이지 문자 수이다. 이는 PDF 이미지·표를 포함한 내용 전체가 이해되었다는 의미가 아니다. 빈 페이지는 미처리로 기록하고 OCR 필요 안내를 제공한다. 최대 구간 제한으로 제외된 페이지도 공개한다. 원본이 100페이지를 초과하면 일부를 조용히 자르지 않고 거부한다.

## 라벨과 평가

기본 진입은 발간일 **다음** 관측 거래일 종가다. 종료 목표일은 **발간일 + 30달력일**이고, 종료는 목표일 이상이며 진입일보다 뒤인 첫 관측 거래일이다. 휴장일은 다음 관측 거래일로 이동한다. `as_of` 이후 가격은 공급자가 반환해도 제거한다. 종료 거래일이 아직 없으면 pending, 가격·메타데이터가 없으면 unavailable이다. 라벨은 반올림 전 수익률이 -5% 이하일 때 1이다. FinanceDataReader 종가의 기업행동/배당 조정 정책은 확인되지 않았다는 점을 함께 저장한다.

고유 발간일을 시간순 약 60/20/20으로 나눈다. 동일 문서 ID/해시/정규화 텍스트/그룹을 중복 제거한 뒤 분할하며, 학습·검증 문서의 라벨 관측 종료일이 다음 구간 시작일 이상이면 제외한다. 이 과정 이후 구간을 생성한다. 학습에 양 클래스와 유효 분할이 없으면 학습을 중단한다. 평가에 양 클래스 또는 각 30문서가 부족하면 manifest에 평가 불충분을 표시한다. 30개 이상이라는 사실 자체는 실전 성능 검증이 아니다.

기준선은 TF-IDF(1~2그램)와 로지스틱 회귀다. 학습 문서별 총 가중치를 맞추고, 학습 데이터의 클래스 가중치를 사용한다. 검증셋 F1로 임계값을 선택하고 테스트셋에는 적용만 한다. 다수 클래스 기준선, precision/recall/F1/average precision(PR-AUC 표기), 혼동행렬, 클래스별 문서·구간 수를 JSON manifest에 저장한다. 정의되지 않는 지표는 null이다. 데이터/모델 크기와 버전·seed·분할 ID·파일 체크섬을 남긴다. 라벨 관측 기간·진입 시점·수익률 기준·실제 가격·출처도 모델에 보존하며 서로 다른 알려진 라벨 정의의 혼합은 거부한다. 정의가 누락되면 unknown/incomplete 및 평가 불충분으로 표시한다. 분류 임계값은 수익률 라벨 기준과 별도 항목이다.

## 저장과 동시성

문서 중복 키는 (owner, content_hash)다. 분석 중복 키는 문서, 엔진, 모델 fingerprint, 실제 처리 설정, 전처리 버전, 분석 당시 메타데이터다. 동일 내용이라도 모델/설정/수정 정보가 바뀌면 별도 실행으로 남는다. 실행에 원문 사본을 포함해 재추출이나 현재 메타데이터 수정이 과거 근거를 바꾸지 않는다.

브라우저 세션에 무작위 복구 키를 발급하고 SHA-256 값을 owner로 사용한다. 모든 DB 쿼리는 owner 범위로 제한한다. 복구 키는 **접근 권한 자체**이므로 안전하게 보관해야 한다. 이는 로컬 개인용 앱의 공간 분리이며 다중 사용자 공개 서비스용 회원 인증/권한/감사 체계를 대체하지 않는다. 데모는 별도 메모리 DB와 owner로 분리되며 프로세스 종료 시 사라진다.

모델은 파일 체크섬과 manifest 버전별 최대 2개 캐시에 보관한다. 로딩·추론에는 잠금을 사용한다. 모델은 공유할 수 있지만 사용자 문서/결과를 모델 캐시에 넣지 않는다. 완료 manifest가 없는 과거 모델은 이유를 표시하고 거부한다. 가중치 로딩은 로컬 파일과 safetensors만 사용하며 임의 pickle을 실행하지 않는다.

백그라운드 작업은 프로세스 내에서 유지된다. UI rerun은 기존 작업을 관찰하며 새 작업을 시작하지 않는다. 앱 프로세스가 종료되면 실행 중 작업은 재개되지 않는다. 수집은 파일별 manifest로 재실행할 수 있고, 완료한 분석은 DB에 남는다. 학습은 임시 디렉터리에서 완성한 후 원자적으로 게시하므로 중단된 모델은 선택되지 않는다. 중지는 문서/학습 단계 경계에서 확인하며 실행 중인 단일 외부 요청은 타임아웃까지 걸릴 수 있다.

## 현재 한계

OCR 엔진은 기본 설치에 없다. 스캔 문서는 OCR 필요로 표시하며 빈 결과를 성공 분석하지 않는다. 필요하면 별도 환경에서 OCRmyPDF/Tesseract 등으로 한국어 OCR을 수행한 검색 가능한 PDF를 입력한다. 해당 OCR 품질과 네이티브 설치는 이번 구현의 검증 범위에 포함하지 않는다.

표의 셀 구조·복잡한 회계 기간·다중 통화 환산·범용 회사명 인식은 완전하지 않다. 자동 추출은 보수적이며 충돌/단위 불명은 미확인으로 둔다. 숫자와 출처를 사용자가 확인해야 한다. 기존 공개 예제 PDF는 보존했다. 노트북은 현행 모듈을 사용하는 모델 없는 실행 예제로 교체했다.

웹 공개 배포, 계정 로그인, 거래 주문, 실시간 시세/투자 권고, 외부 생성형 AI 요약은 구현하지 않았다.
